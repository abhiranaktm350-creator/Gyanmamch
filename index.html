Gyan Manch Official Edition — Localhost, LAN & Full PDF Import Guide

Run on a single computer without internet, or share across all Library PCs on the same network.

Step 1: Student Registration & Pending Approval Gate

Click + Register New Student in the top bar (or switch to Pending Student Kavita). Try starting any mock test—the system blocks access and displays a clear Pending Approval notice.

Step 2: Admin Approves Student & Reviews/Publishes Questions

Click 3. Library Admin Console in the top bar. Approve pending students with one click, add bilingual (English + Hindi) questions, or run the PDF-to-Questions Extractor & review staging screen.

Step 3: Take Bilingual Timed Test & Start Separate Retakes

Switch to your approved student, start a full mock test or chapter test, toggle between English / Hindi / Both, mark questions for review, and submit. Reopening the same test generates a brand-new Attempt ID without overwriting previous attempts.

Production / Free-Tier Transparency Notes
  • Database Mode: Currently running in self-contained Browser LocalStorage Sandbox Mode so every workflow works immediately offline/in-Canvas. Full PostgreSQL schema, Row-Level Security (RLS) policies, and server-side scoring RPC (`submit_and_score_attempt`) are provided in the accompanying deployment package (`supabase_schema.sql`).
  • PDF Extraction & OCR: Selectable English & Devanagari PDFs are parsed locally via Mozilla PDF.js. Heavy scanned PDFs without selectable text can use the built-in CSV Bulk Import Fallback or sample PDF generator.
